# 🐾 We Care


## 📖 Sobre o projeto

O **We Care** é um projeto desenvolvido com o objetivo de criar uma interface moderna, simples e intuitiva voltada para o **cuidado e bem-estar dos animais**.

A proposta é proporcionar uma experiência agradável aos usuários, utilizando um design amigável e elementos visuais que transmitem carinho, cuidado e confiança.

## 🎯 Objetivo

O principal objetivo do **We Care** é desenvolver uma interface responsiva e visualmente agradável, colocando em prática conceitos de:

- 🎨 Design de interfaces
- 📱 Responsividade
- 💻 Desenvolvimento Web
- 🧩 Organização de componentes
- 🐶 Experiência do usuário (UX)



O projeto foi desenvolvido pensando em diferentes tamanhos de tela, permitindo uma boa experiência tanto em **computadores quanto em dispositivos móveis**.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
